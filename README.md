# Data for the "Relative consistency is not a feature of Sample Entropy" paper by Żurek et.al.

## R code

`samp_ens.R` contains all the functions used to get the statistics of the crossings in the Sample Entropy profiles from the 86 analyzed RR interval time series

`analysis.R` code that carries out the actual analysis and draws plots

## Data

The `RR-SampEn-data` folder contains the raw data for the SampEn profiles for the analyzed RR interval time series.
